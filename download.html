How to install

Six steps, about a minute.

  1. Tap Download.
  2. If Chrome warns about the file type, tap "Download anyway".
  3. Open the file from the notification, or from Files > Downloads.
  4. If Android asks, allow "Install unknown apps" for Chrome (Settings > Apps > Chrome > Install unknown apps).
  5. Tap Install. If Google Play Protect shows a warning, tap "More details" > "Install anyway".
  6. Open Weflux, sign in, and allow notifications.

Keep Chrome installed. The app runs on Google Chrome, so keep Chrome installed and updated on your phone.
